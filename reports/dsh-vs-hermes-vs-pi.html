2 架构哲学

🔷 DeepSeek Harness

"Everything is a Plugin"
  • 由 Cordis 框架驱动（有配套论文）
  • 模型适配器、工具注册表、会话日志、连 Agent 循环本身都是插件
  • 没有特权核心——扩展方式 = 挂载一个插件
  • Profile + Bundle 组合机制（分层 patch）
  • 事件驱动扩展（Session/Agent/Capability 三类事件）
  • 插件卸载时注册的 effect 自动回滚

🟡 Hermes Agent

"Narrow Waist + Edges"
  • 核心窄腰——每个 model tool 随每次 API 调用发送
  • 能力在边缘扩展：CLI 命令+skill、plugin、MCP server
  • Prompt caching 神圣不可侵犯——不改过去上下文
  • Profile 隔离（独立 config/skills/memory/cron）
  • 多平台 Gateway（同一 agent core 驱动 CLI/TUI/Desktop/Chat）
  • 自进化：技能从经验中学习，跨会话持久记忆

🔴 Pi Agent (Rust)

"Native + Secure by Design"
  • Rust 2024 edition，零 unsafe 代码
  • asupersync 结构化并发运行时
  • rich_rust 终端 UI（Rich 的 Rust 移植）
  • 能力门控安全模型（capability-gated hostcalls）
  • 扩展信任生命周期：pending→acknowledged→trusted→killed
  • Tamper-evident 运行时风险账本（可审计/回放）

8 优劣势分析

🔷 DeepSeek Harness

优势
  • 一切皆插件——连 agent loop 都可替换
  • Cordis 有论文支撑的理论基础
  • 首日 27k stars，生态爆发力极强
  • 中英双语文档 + 企微社区（国内友好）
  • 50+ 包覆盖极广（含 e2b 云沙箱、LSP）
  • Profile+Bundle 层层 patch 的组合机制
不足
  • Developer Preview——明说会有 breaking changes
  • 无多平台 Gateway（不能接飞书/TG/Discord）
  • 无桌面应用
  • Cordis 框架学习曲线陡峭
  • 无浏览器自动化
  • 生产就绪度未知

🟡 Hermes Agent

优势
  • 230k stars——最成熟的社区
  • 20+ 平台 Gateway（飞书/TG/Discord/Slack...）
  • 自进化：86+ skills 从经验中学习
  • 多界面：CLI/TUI/Desktop/Dashboard/Chat
  • Python 生态——贡献门槛最低
  • 跨会话持久记忆 + profile 隔离
  • delegate_task 并行子 Agent
  • 浏览器自动化
不足
  • Python 运行时开销比 Rust/编译型大
  • 核心窄腰哲学限制了核心扩展速度
  • 安全模型不如 Pi Agent 精细
  • 无 kill-switch / 审计账本
  • 无 Cordis 式"一切皆插件"彻底性

🔴 Pi Agent (Rust)

优势
  • 单二进制——启动极快，零依赖
  • 零 unsafe Rust——内存安全保证
  • 安全模型最先进：能力门控+kill-switch+审计账本
  • 两阶段 exec 拦截危险命令（含 AST 检测）
  • 扩展信任生命周期（pending→trusted→killed）
  • asupersync 结构化并发——可预测的取消/生命周期
  • 性能基准有证据门禁（不虚假宣传）
不足
  • 生态最小（1.6k stars）
  • 无 Web UI / 桌面应用
  • 无多平台 Gateway
  • 无 MCP 支持
  • 无 cron/调度
  • 无 skills 知识库系统
  • Rust 贡献门槛最高
  • CLI 专注——不适合非编程场景

9 适用场景推荐

🔷

选 DSH 如果你…

需要极致的插件化架构，想替换 agent loop 本身；做 TS/Node.js 技术栈的团队产品；需要 e2b 云沙箱或 LSP 集成；想搭一个可深度定制每一层的 agent 平台。适合平台型团队而非个人用户。

平台开发深度定制TS/Node云沙箱
🟡

选 Hermes 如果你…

需要多平台 Gateway（飞书/TG/Discord/Slack）；需要自进化+持久记忆；需要多界面（CLI/Desktop/Web）；做 AI for 业务（非纯编程）；团队用 Python；需要浏览器自动化+数据查询 Agent。适合业务型团队和个人。

多平台AI for 业务自进化Python浏览器
🔴

选 Pi Agent 如果你…

是个人开发者，要一个极快极安全的 CLI 编程助手；在意安全审计和 kill-switch；跑在资源受限环境需要单二进制；做安全敏感的代码任务；不需要 Web/多平台/调度。适合安全极客和个人编程者。

CLI 编程安全优先单二进制Rust

💡 核心洞察

三个框架代表了 Agent 架构的三种哲学：DSH 追求"插件极致化"（连 loop 都可替换），Hermes 追求"全平台覆盖+自进化"（20+ 平台 + skills 学习），Pi Agent 追求"安全极致+性能极致"（Rust 零 unsafe + 能力门控）。这不是同一赛道的三选一，而是三种不同维度的极致——选哪个取决于你最看重哪个维度。对你（data Agent 开发者 + 业务型 Agent）而言，Hermes 的多平台 Gateway + 自进化 skills + 浏览器自动化最对口；DSH 的"一切皆插件"值得学习其架构思想，但目前不适合上生产。
