DataSpace: Benchmarking Data Agents for Verifiable Analytics over Heterogeneous Workspaces

2026-08-04 · arXiv 2608.03451
提出了 DataSpace 基准，用于在异构工作区（多数据源、多格式）上评测数据 Agent 的可验证分析能力。它强调分析结果需要可验证（verifiable），覆盖数据混洗、多源 join、格式转换等真实场景。
🔍 技术视角：对做数据分析 Agent 的团队是很好的评测参考：'可验证'是当前数据 Agent 商业化落地最欠缺的一环，这个基准能帮你检验自己的 Agent 在复杂异构数据上是否真的可信，而不只是跑通 demo。

BAP-SQL: Budget-Aware Observation Planning for Agentic Text-to-SQL

2026-08-03 · arXiv 2608.02876
针对 Agentic Text-to-SQL 中 token/成本消耗过高的问题，提出预算感知的观察规划（BAP）策略，让 agent 在有限的调用预算内规划观察步骤，在保证准确率的同时显著降低开销。
🔍 技术视角：很贴合生产环境痛点：多步 agent 的推理成本常被忽略。如果你在做 SQL Agent 上线，这类'预算约束下的规划'是控制运行成本的关键思路，值得读全文了解其规划策略。

DataClawEval: A Benchmark for Data Engineering Agents in Real Industrial Harness

2026-07-30 · arXiv 2607.28033
面向真实工业场景的数据工程 Agent 基准，评测 agent 在数据清洗、特征工程、管线搭建等工业级任务上的表现，强调贴近真实生产 harness 而非玩具数据集。
🔍 技术视角：数据工程 Agent 与纯数据分析不同，更贴近你团队可能实际要做的 pipeline 工作。这个基准能帮你对照自家 Agent 在工业任务上的真实水平。
